# 🦦 Flapotter - La Loutre Tech

**Un jeu pédagogique pour apprendre les bases de la tech en s'amusant !**

---

## 🎮 **Jouer maintenant**

### Option 1 : **Ouvrir directement dans ton navigateur** (recommandé)
👉 **[Jouer à Flapotter sur GitHub Pages](https://royal63.github.io/D-moduchat/flapotter/)** *(lien actif après déploiement)*

> ⚠️ *Si le lien ne fonctionne pas encore, attends 1-2 minutes le temps que GitHub Pages se déploie.*

---

### Option 2 : **Lancer en local**
1. Télécharge le dossier `flapotter` depuis ce repo.
2. Ouvre le fichier **`index.html`** dans ton navigateur (double-clic).
3. C'est parti !

---

## 📖 **Comment ça marche ?**

### 🎯 **But du jeu**
Aide la loutre à éviter les algues (obstacles) pour **accumuler des points**.
À chaque **palier de 5 points**, tu débloques :
- Une **info tech** (pour apprendre).
- Des **compétences (skills)** à 10, 20 et 30 points (pour t'aider).

---

## ⌨️ **Contrôles**

| Action               | Touche / Clic          | Description                          |
|----------------------|------------------------|--------------------------------------|
| Sauter               | **Espace** ou **Clic** | Fait sauter la loutre.               |
| Activer Double Saut  | **D**                 | Permet de sauter 2 fois (débloqué à 10 pts). |
| Activer Bouclier     | **S**                 | Protège des collisions (5s, à 20 pts). |
| Activer Ralentissement | **F**              | Ralenti les obstacles (5s, à 30 pts). |
| Recommencer          | **Espace** ou **Clic** | Après un Game Over.                  |

---

## 🛡️ **Les Compétences (Skills)**

| Points | Compétence       | Effet                                                                 | Touche |
|--------|------------------|-----------------------------------------------------------------------|-------|
| 10     | **Double Saut**   | Permet de sauter une 2ème fois en l'air.                              | D     |
| 20     | **Bouclier**      | Te protège des collisions pendant 5 secondes.                        | S     |
| 30     | **Ralentissement**| Ralenti les obstacles pendant 5 secondes.                            | F     |

> 💡 *Les compétences sont **réutilisables** après un cooldown (5s pour le bouclier/ralentissement).*

---

## 🎓 **Pourquoi ce jeu ?**

Flapotter est conçu pour :
1. **Rendre la tech accessible** : Pas besoin d'être un expert pour comprendre les concepts de base.
2. **Apprendre en s'amusant** : Les infos tech sont intégrées naturellement dans le gameplay.
3. **Encourager la curiosité** : Chaque palier donne envie d'aller plus loin.
4. **Être inclusif** : Adapté à tous les âges et tous les niveaux.

---

## 🔧 **Technologies utilisées**

- **Frontend** : HTML5, CSS3, JavaScript (Vanilla, pas de dépendances).
- **Design** : 100% CSS (pas d'images externes).
- **Hébergement** : GitHub Pages (gratuit et instantané).

## 🤝 **Contribuer à la pédagogie**

Tu veux ajouter une **info tech** ou une **compétence** ?
1. **Fork** ce repo.
2. Modifie le fichier `flapotter/index.html` (cherche `INFOS_TECH` ou `SKILLS`).
3. Ouvre une **Pull Request** avec tes changements.

### Exemple pour ajouter une info tech :
```javascript
{
    milestone: 45, // Points nécessaires
    title: "Le Terminal",
    text: "Le terminal, c'est comme une télécommande pour ton ordinateur !"
}
```
